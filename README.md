# منظومة الفارابي ERP الذكية — العرض التقديمي التنفيذي العالمي
# Alfarabi Enterprise ERP — Global 3D Executive Keynote Presentation

منظومة عرض تفاعلية ثلاثية الأبعاد (3D Interactive Keynote) مصممة للإدارة العليا والمستثمرين والشركاء الدوليين لشركة **الفارابي (Alfarabi)**، تقدم حلولاً هندسية متكاملة لربط أربعة قطاعات تشغيلية حيوية:
1. **وثائق العمالة والأرشيف الرقمي (Workforce Identity, Dossier & Document Security)**
2. **إدارة السكنات والغياب (Camp Housing Intelligence & 10-Day Retention Policy)**
3. **الإعاشة وحوكمة التغذية (Catering Precision & 1-Worker-1-Meal Governance)**
4. **الحركة وأسطول الأتوبيسات (Transit Dispatch & Capacity Balancing)**

---

## 🌍 التحول العالمي وثنائية اللغة (Arabic ⇄ English Bilingual Engine)

- **زر تبديل فوري للغة في الهيدر**: التبديل بنقرة واحدة بين **اللغة العربية الفصحى** و**اللغة الإنجليزية الدولية (International Enterprise English)**.
- **تخطيط ديناميكي للاتجاه**: تحول فوري وسلس بين RTL و LTR، مع تكييف اتجاهات الأسهم وأزرار التنقل.
- **صياغة عالمية بمستوى استشارات كبرى (Fortune 500 / Big-4 Consulting Style)**: تمت صياغة كل شريحة بمصطلحات استراتيجية دقيقة ومقاييس عائد استثماري (ROI) ونقاط حوكمة واضحة لتقديمها أمام كبرى الشركات الدولية.

---

## 🔊 نظام صوتي سينمائي فائق الدقة (Studio-Grade Sound Engine)

- تم تحديث المحرك الصوتي ليعمل بمعايير استوديوهات الصوت الاحترافية باستخدام Web Audio API:
  - **صوت انتقال الشرائح (Slide Transition)**: تموج سينمائي دافئ يدمج ترددات الـ Sub-Bass المنخفضة مع هواء ناعم ونغمة بلورية (Warm Cinematic Whoosh).
  - **صوت النقر واللمس (Tactile Haptic Click)**: نقر ناعم وفخم مستوحى من واجهات Apple الحديثة.
  - **نغمة التفاعل والمحاكاة (Harmonic Trigger Chime)**: تآلف موسيقي رباعي عالي النقاء عند تشغيل محاكاة الأثر التتابعي أو تعديل حالة الأسرة ثلاثية الأبعاد.
  - إمكانية **كتم وتشغيل الصوت فورياً (Mute/Unmute)** بضغطة واحدة من أيقونة السماعة في الهيدر.

## 🔮 منظومة حل المشكلات الذكية 3D العالمية (Global 3D Problem-Resolution Engine)

- **شريحة تفاعلية متطورة (الشريحة 3 - تشخيص التحديات والمعالجة الجذرية)**:
  - **محاكاة 3D تفاعلية كاملة (Three.js WebGL)**: استعراض الفارق بين **الوضع التقليدي المأزوم (Legacy Friction Mode)** بأضوائه التحذيرية وأنابيب البيانات المتكسرة، وبين **وضع معالجة الفارابي المتطور (Alfarabi 3D Solution)** بنواته الكريستالية المشعة وقنوات الليزر السريعة.
  - **فحص العقد الخمس ثلاثية الأبعاد (5-Pillars Interactive Nodes)**:
    1. **أرشيف وهوية العمالة (DOCS)**: حل أزمة فقدان الأوراق والغرامات ➔ خزانة رقمية مشفرة وتنبيهات قبل 30 يوم واسترجاع في 0.8 ثانية.
    2. **السكنات والأسرة الوهمية (HOUSING)**: حل نزيف الإيجارات المهدرة لعمال غائبين ➔ إخلاء آلي بعد 10 أيام واسترداد 28% من ميزانية السكن.
    3. **الإعاشة وحوكمة التغذية (CATERING)**: حل طبخ وجبات فائضة ترمى بالقمامة ➔ حوكمة الحصة الواحدة (1 عامل = 1 وجبة) برمز باركود متزامن مع بوابات الحضور.
    4. **أسطول النقل والأتوبيسات (TRANSIT)**: حل الحافلات الخالية وهدر الوقود ➔ توجيه ديناميكي ودمج حمولات الركاب بنسبة إشغال 94%.
    5. **الحوكمة وسجل التدقيق (GOVERNANCE)**: حل تضارب الإكسيل والتنصل من المسؤولية ➔ نواة مركزية واحدة (Single Source of Truth) وسجل تدقيق مشفر غير قابل للتلاعب.
  - **حاسبة استرداد العائد المالي الفوري (Value Recovery Calculator)**: محاكاة حجم العمالة المشغلة (من 500 إلى 15,000 عامل) وحساب التوفير المالي المحقق شهرياً وسنوياً.
- **نافذة مركزية عامة (Global Problem Solver Modal)**: زر متوهج دائم في الهيدر أو ضغط مفتاح **`P`** يتيح لمجلس الإدارة استدعاء محرك حل المشاكل ثلاثي الأبعاد من أي شريحة خلال الاجتماع.

## 🚀 كيفية تشغيل العرض محلياً (Run Locally)

الخادم المحلي يعمل حالياً على:
👉 **`http://localhost:5173/`**

لتشغيله مجدداً في أي وقت:
```bash
# تثبيت الاعتماديات (إذا لم تكن مثبتة)
npm install

# تشغيل خادم التطوير
npm run dev
```

## ⌨️ اختصارات لوحة المفاتيح للتنقل السريع

| المفتاح | الوظيفة |
| :--- | :--- |
| **Space** أو **السهم المتقدم** | الانتقال للشريحة التالية (Next Slide) |
| **السهم العكسي** أو **Backspace** | العودة للشريحة السابقة (Previous Slide) |
| **P** | فتح / إغلاق محرك حل المشاكل الذكي 3D (Problem Solver 3D) |
| **N** | فتح / إغلاق دليل ملاحظات المتحدث التنفيذي (Presenter Notes) |
| **T** | فتح / إغلاق فهرس المحتوى (Agenda / Table of Contents) |
| **F** | ملء الشاشة الكامل (Fullscreen Presentation Mode) |
| **Home** | الانتقال للشريحة الأولى (Slide 1) |
| **End** | الانتقال للشريحة الختامية (Slide 18) |
| **Esc** | إغلاق النوافذ المنبثقة |
